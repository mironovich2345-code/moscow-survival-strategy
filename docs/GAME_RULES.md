# Game Rules

Числовые правила. Все константы живут в коде (`src/game/**`) — при изменении
правила обновлять и этот файл, и тесты.

## Время

| Правило | Значение | Константа |
|---|---|---|
| Длительность хода | 2 игровых часа | `HOURS_PER_TURN` (`src/game/time`) |
| Старт кампании | День 10, 08:00 | `CAMPAIGN_START_DAY`, `CAMPAIGN_START_HOUR` |

Время хранится как абсолютный час с момента катастрофы (день 1, 00:00).

## Группа

| Правило | Значение | Константа |
|---|---|---|
| Максимальный размер группы | 12 | `MAX_GROUP_SIZE` (`src/game/characters`) |
| Максимальный боевой отряд | 5 | `MAX_SQUAD_SIZE` (`src/game/expeditions`) |
| Герой | ровно 1 на кампанию | проверяется в `createNewGame` |

## Ресурсы

`food`, `water`, `medicine`, `ammunition`, `fuel`, `materials`.
Целые неотрицательные числа; запас не может опуститься ниже 0.

Стартовые запасы прототипа (`src/data/content.ts`): food 20, water 20,
medicine 2, ammunition 24, fuel 10, materials 15.

## Персонажи

- Характеристики: strength, agility, endurance, perception, intelligence.
- Навыки: firearms, melee, medicine, scavenging, stealth.
- Экипировка: слоты weapon, armor, backpack.
- Состояние: health / maxHealth; назначение (`base` / `expedition`).
- В отряд можно взять персонажа, который на базе и жив (health > 0).

В 0.1 характеристики и навыки **не влияют** на результаты — это задел.

## Экспедиции

- Отряд: 1–5 уникальных доступных персонажей.
- Длительность задаётся локацией (`expeditionTurns`).
- Отряд возвращается в конце хода, на котором `time >= returnsAt`.
- Добыча: для каждой записи `loot` локации бросается `nextInt(min, max)`.
- Аптека (Лефортово): 3 хода, medicine 1–5.

## Случайность

- Вся случайность — только через `src/game/random` (mulberry32).
- Состояние RNG хранится в `GameState.rng` и сохраняется вместе с игрой:
  одинаковый seed + одинаковые команды = одинаковый результат.
- `Math.random()` в игровой логике запрещён (допускается только в UI для
  генерации seed новой игры).
