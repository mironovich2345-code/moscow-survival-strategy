# Core Loop

## Целевой цикл (кампания)

1. **База:** оценить состояние группы и запасы.
2. **Карта:** выбрать район и точку интереса.
3. **Отряд:** собрать отряд (до 5 человек) и отправить его.
4. **Время:** завершать ходы (1 ход = 2 часа), пока отряды в пути.
5. **Результат:** отряд возвращается с добычей (или с потерями — в будущих версиях).
6. **Решения:** распределить ресурсы, лечить, укреплять базу — и снова к п. 1.

## Prototype 0.1 — реализованная часть цикла

```
База ──[Карта]──► Карта ──[Аптека]──► Выбор отряда ──[Отправить]──►
  ▲                                                                 │
  └──── возврат + medicine ◄── [Следующий ход] × N ◄────────────────┘
```

- Поход в «Аптеку» (Лефортово) занимает 3 хода = 6 часов.
- По возвращении отряд приносит 1–5 medicine (детерминированный RNG).
- Каждое действие сохраняется в `localStorage`.

## Prototype 0.2 — осмысленный survival-цикл

```
База ─► Карта ─► Локация (время, риск, добыча) ─► Отряд ─► Отправить
  ▲                                                          │
  │        ┌──────────── [Следующий ход] ◄───────────────────┤
  │        │                                                 │
  │   каждый ход: 25 % — событие ─► пауза ─► выбор решения ──┘
  │   00:00 — суточный расход еды и воды (голод / жажда)
  │
  └──── возврат: добыча локации × бонус поиска + груз событий
```

Что даёт решения игроку:
- **Какую локацию выбрать:** еда/вода (продуктовый) против медикаментов,
  топлива и материалов, патронов — при постоянном суточном расходе.
- **Кого отправить:** навык поиска отряда увеличивает добычу.
- **Как реагировать на событие:** риск против времени и ресурсов.

## Не входит в 0.2

Бой, ранения и смерть от голода, влияние риска, фракции, инвентарь,
крафт, найм, строительство.
