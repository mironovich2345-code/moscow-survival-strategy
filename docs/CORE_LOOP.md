# Core Loop

## Целевой цикл (кампания)

1. **База:** оценить состояние группы и запасы.
2. **Карта:** выбрать район и точку интереса.
3. **Отряд:** собрать отряд (до 5 человек) и отправить его.
4. **Время:** завершать ходы (1 ход = 2 часа), пока отряды в пути.
5. **Результат:** отряд возвращается с добычей (или с потерями — в будущих версиях).
6. **Решения:** распределить ресурсы, лечить, укреплять базу — и снова к п. 1.

## Prototype 0.1 — реализованная часть цикла

```
База ──[Карта]──► Карта ──[Аптека]──► Выбор отряда ──[Отправить]──►
  ▲                                                                 │
  └──── возврат + medicine ◄── [Следующий ход] × N ◄────────────────┘
```

- Поход в «Аптеку» (Лефортово) занимает 3 хода = 6 часов.
- По возвращении отряд приносит 1–5 medicine (детерминированный RNG).
- Каждое действие сохраняется в `localStorage`.

## Prototype 0.2 — осмысленный survival-цикл

```
База ─► Карта ─► Локация (время, риск, добыча) ─► Отряд ─► Отправить
  ▲                                                          │
  │        ┌──────────── [Следующий ход] ◄───────────────────┤
  │        │                                                 │
  │   каждый ход: 25 % — событие ─► пауза ─► выбор решения ──┘
  │   00:00 — суточный расход еды и воды (голод / жажда)
  │
  └──── возврат: добыча локации × бонус поиска + груз событий
```

Что даёт решения игроку:
- **Какую локацию выбрать:** еда/вода (продуктовый) против медикаментов,
  топлива и материалов, патронов — при постоянном суточном расходе.
- **Кого отправить:** навык поиска отряда увеличивает добычу.
- **Как реагировать на событие:** риск против времени и ресурсов.

## Prototype 0.3 — склад, экипировка, подготовка похода

```
Склад ──► экипировка (снять / передать / надеть)
  │
  ▼
Карта ─► Локация ─► Участники + их экипировка ─► Припасы отряда
                                                   │  (сразу уходят со склада)
                              Груз ≤ Грузоподъёмность? ── нет ─► нельзя отправить
                                                   │ да
                                                   ▼
   в пути: события тратят припасы отряда, находки — в пределах вместимости,
           в полночь отряд ест свои припасы (нет — голод/жажда)
                                                   │
                                                   ▼
   возврат: остаток припасов + найденное + добыча (что влезло) ─► склад
```

Новые решения игрока:
- **Сколько взять:** больше припасов — безопаснее в пути, но меньше места
  под добычу и меньше запасов на базе.
- **Кто что несёт:** рюкзак сильно увеличивает вместимость — кому его дать.
- **Чем платить в событиях:** «Застрелить» доступно, только если взяли патроны.

## Prototype 0.3.1 — предметы в добыче

- Парковка и отдел полиции с небольшим шансом дают уникальные предметы
  (рюкзак, монтировка, дробовик, бронежилет).
- Локация обыскивается в середине похода: найденное сразу видно в
  «Найдено» у активной экспедиции и занимает место в грузе — тяжёлая
  находка может не поместиться.
- По возвращении предмет попадает на склад и надевается обычной экипировкой.
- Патроны в подготовке: −10 / −1 / +1 / +10 / MAX.

## Prototype 0.4 — бой

```
Событие «Один заражённый» ─► Вступить в бой / Избежать (30 % — заметил)
                                   │
                                   ▼
Расстановка FRONT/BACK ─► Раунд: действие каждому (атака / защита / смена линии /
                          медикаменты) ─► заражённые кусают FRONT ─► шум → подкрепление?
                                   │            ▲
                                   ├────────────┘ пока все живы и враги живы
                                   ▼
        Победа → поход продолжается, вещи павших подбирают (если влезут)
        Отступление → поход прерван, отряд идёт домой
        Гибель → экспедиция потеряна, вещи остаются в локации
```

Решения игрока в бою: чем стрелять (патроны экспедиции и шум), кого ставить
вперёд, когда лечиться, когда уходить. Раны и смерти остаются после боя.

## Prototype 0.5 — первый найм

Кампания начинается одним Героем. Максим ждёт в своём фитнес-клубе:

```
Карта ─► «Фитнес-клуб Максима» (Герой обязателен) ─► прибытие ─► «Знакомая машина»
   ├─ Уйти ─────────────► поход прерван, можно вернуться
   └─ Войти ─► «Максим» ─┬─ Пойдём со мной ─► Максим в группе (топор, рюкзак), идёт домой с отрядом
                         ├─ Оставайся здесь ─► ждёт; следующий визит: «Максим ждёт»
                         └─ Каждый сам за себя ─► отказ (флаг для будущих этапов)
```

Решение игрока: взять Максима сразу, позже или не брать вовсе. Его отношение
к Герою (trust) зависит от выбора. Профиль члена группы — по клику на имя.

## Не входит в 0.3

Бой, ранения и смерть от голода, влияние риска, фракции, крафт, калибры,
ручные пайки, сетка инвентаря, найм, строительство.
