# Moscow Survival Strategy — Prototype 0.2

Пошаговая survival-стратегия про Москву после биологической катастрофы.
Кампания начинается на 10-й день; база группы — ЖК «Статус» в Лефортово.

## Требования

- Node.js **22.12+** (или 20.19+ только для запуска Vite; тестам нужен 22.12+)
- npm

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Vite |
| `npm test` | Unit-тесты игровой логики (Vitest) |
| `npm run test:watch` | Тесты в watch-режиме |
| `npm run typecheck` | Проверка типов |
| `npm run build` | Проверка типов + production-сборка в `dist/` |
| `npm run preview` | Просмотр собранной версии |

## Как играть (0.2)

1. На экране базы — день, время, ресурсы, группа (Герой и Максим) и журнал.
2. **Карта** → Лефортово → выберите локацию: Аптека, Продуктовый магазин,
   Подземная парковка или Отдел полиции. Видны базовое время, риск и
   возможная добыча — с учётом навыка поиска выбранного отряда.
3. Отметьте участников (до 5) и нажмите **Отправить отряд**.
4. Нажимайте **Следующий ход (+2 ч)**. В пути может случиться событие —
   игра остановится и покажет выбор. После решения поход продолжится.
5. В полночь каждый живой член группы съедает 1 еду и выпивает 1 воду.
   Если не хватает — персонаж получает статус «голоден» / «жажда».
6. Прогресс сохраняется автоматически в `localStorage`; сейвы 0.1
   мигрируются. **Новая игра** на экране базы сбрасывает сейв.

Все правила и формулы — в `docs/GAME_RULES.md`.
