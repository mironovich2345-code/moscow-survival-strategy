# Moscow Survival Strategy — Prototype 0.1

Пошаговая survival-стратегия про Москву после биологической катастрофы.
Кампания начинается на 10-й день; база группы — ЖК «Статус» в Лефортово.

## Требования

- Node.js **22.12+** (или 20.19+ только для запуска Vite; тестам нужен 22.12+)
- npm

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Vite |
| `npm test` | Unit-тесты игровой логики (Vitest) |
| `npm run test:watch` | Тесты в watch-режиме |
| `npm run typecheck` | Проверка типов |
| `npm run build` | Проверка типов + production-сборка в `dist/` |
| `npm run preview` | Просмотр собранной версии |

## Как играть (0.1)

1. На экране базы видны день, время, ресурсы, группа (Герой и Максим) и журнал.
2. **Карта** → район **Лефортово** → **Аптека**.
3. Отметьте участников отряда (до 5) и нажмите **Отправить отряд**.
4. Нажимайте **Следующий ход (+2 ч)** — поход длится 3 хода (6 часов).
5. Отряд возвращается и приносит 1–5 медикаментов.
6. Прогресс сохраняется автоматически в `localStorage` — после перезагрузки
   страницы игра продолжается. **Новая игра** на экране базы сбрасывает сейв.
