# Moscow Survival Strategy — Prototype 0.6

Пошаговая survival-стратегия про Москву после биологической катастрофы.
Кампания начинается на 10-й день; база группы — ЖК «Статус» в Лефортово.

## Требования

- Node.js **22.12+** (или 20.19+ только для запуска Vite; тестам нужен 22.12+)
- npm

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Vite |
| `npm test` | Unit-тесты игровой логики (Vitest) |
| `npm run test:watch` | Тесты в watch-режиме |
| `npm run typecheck` | Проверка типов |
| `npm run build` | Проверка типов + production-сборка в `dist/` |
| `npm run preview` | Просмотр собранной версии |

## Как играть (0.3.1)

1. На экране базы — ресурсы, группа (Герой и Максим), **Склад** и журнал.
2. **Склад** показывает ресурсы и все уникальные предметы: тип, вес и у кого
   они сейчас. Предметы можно снимать, передавать другому персонажу и
   выдавать со склада — в карточке персонажа или прямо в таблице склада.
3. **Карта** → Лефортово → выберите локацию (Аптека, Продуктовый магазин,
   Подземная парковка, Отдел полиции). Видны время, риск и возможная добыча.
4. Отметьте участников (до 5). Для каждого видно снаряжение и
   грузоподъёмность, экипировку можно поменять тут же.
5. **Припасы отряда**: кнопками − / + выберите food, water, medicine,
   ammunition. Строка «Груз: X / Y» показывает загрузку; при перегрузе
   отправить нельзя. Припасы сразу уходят со склада.
   Для патронов есть −10 / −1 / +1 / +10 / MAX (MAX — сколько есть и влезает).
6. **Следующий ход (+2 ч)**. События тратят припасы отряда. В середине похода
   отряд обыскивает локацию: найденное (включая уникальные предметы с
   парковки и из полиции) видно в «Найдено» и ограничено свободным местом.
   В полночь отряд ест свои припасы.
7. По возвращении остаток припасов, добыча и найденные предметы поступают
   на склад; предмет можно сразу надеть через «Выдать…» или карточку персонажа.
8. Прогресс сохраняется в `localStorage`; сейвы 0.1–0.3 мигрируются.

### Мир и Арена (0.6)

- На карте у каждого разведанного района — контроль, шум и угроза.
  Бои поднимают шум района, он постепенно спадает; чем выше угроза, тем
  чаще отряды натыкаются на заражённых.
- В Соколиной горе хозяйничает Арена. Первый визит («Окраина промзоны») —
  встреча с её людьми: заплатить, отказаться или попытаться уйти.
- Экран «Фракции» — что известно об Арене: отношения, осведомлённость,
  примерная численность, замеченная активность. Точных чисел нет.

### Сюжет (0.5)

- Новая игра начинается **только с Героем**. На карте в Лефортово —
  «Фитнес-клуб Максима» (метка «сюжет»); в этот поход Герой обязателен.
- По прибытии — сюжетная сцена: можно уйти и вернуться позже, войти, найти
  Максима и позвать его в группу, оставить его в клубе или отказаться.
- Позванный Максим сразу входит в отряд со своим топором и рюкзаком и идёт
  на базу вместе с Героем.
- Клик по имени персонажа на базе открывает профиль: навыки, черты,
  экипировка, роль в бою, отношение к Герою.
- Старые сохранения (где Максим был в группе с самого начала) открываются
  без изменений.

### Бой (0.4)

- В пути может встретиться «Один заражённый»: «Вступить в бой» открывает
  экран боя (попытка избежать иногда тоже заканчивается боем).
- До первого раунда расставьте отряд по линиям FRONT / BACK (не больше 3 в линии).
  Ближнее оружие работает только из FRONT, огнестрел — отовсюду и тратит
  патроны отряда.
- Каждому выберите действие (атака: оружие + цель; защита; смена линии;
  медикаменты) и нажмите «Подтвердить раунд». Или попробуйте отступить.
- Шум стрельбы привлекает новых заражённых. Погибшие остаются погибшими,
  их вещи — на месте боя, пока товарищи не подберут их после победы.
- Для проверки: откройте игру с `?dev` в адресе (или `npm run dev`) —
  у активной экспедиции появится кнопка «DEV: бой с 1–4 заражёнными».

Все правила, формулы, веса — в `docs/GAME_RULES.md`.
